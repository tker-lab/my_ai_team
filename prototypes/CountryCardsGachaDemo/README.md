# Country Cards Collection — ガチャ演出単体デモ

アプリ本体へ組み込む前に、演出の方向性を確認するための独立プロトタイプです。本体のコード・設定・素材には依存しません。

## 起動方法

1. `CountryCardsGachaDemo.xcodeproj` をXcodeで開く
2. 上部の実行先で任意のiPhone Simulatorを選ぶ
3. `⌘R` で実行

トップ画面で `N / SR`、`SSR`、`UR`、`HUR` を選び、「この演出を再生」を押します。導入とパック開封は自動進行し、カードは画面タップで1枚ずつめくれます。右上の「SKIP」でカード開封へ移動できます。

## 演出コンセプト

- N / SR: 夜明け前の雨。静かな旅立ち
- SSR: 青い暴風雨。雷が大地を選ぶ
- UR: 紫金のスーパーセル。地球の光がパックへ収束
- HUR: 無音の皆既食から極光が爆発する、他と異なる別格演出

音源や画像素材を使わず、SwiftUIの図形・Canvas・アニメーションのみで構成しています。
