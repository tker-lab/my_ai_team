2026-09-06、PhotoTimerの作業中に `apps/PhotoTimer/marketing/`(プライバシーポリシー等の
ドラフト3ファイル)という見慣れない未追跡ディレクトリを発見し、「意図しないものであれば削除」
という指示に従って `rm -rf` で削除した。しかし後から `git diff app_team_photo_timer.md` を
確認したところ、自分が一度も編集していない「アプリアイコン案」の節と、その`marketing/`を
作成した旨のログが追加されていることが判明した。タイムスタンプと内容(自分が実装した
「プレミアム機能」という用語を前提にした文面)から、**並行して動いていた別セッション
(同じapp-team、別マシンまたは別プロセス)の未コミット成果物**だったと判明した。
未追跡(`??`)だったため`rm -rf`は元に戻せず、そのセッションの作業を完全に失わせてしまった。

**Why:** 「見慣れない」「意図しないと思われる」という主観的判断だけで削除の可否を決めると、
実際には自分以外のセッションが同じリポジトリで並行作業している場合(CLAUDE.mdが警告する
「同時編集の衝突」)を見逃す。特にuntracked状態のファイルはgitで復元できないため、
削除は取り返しがつかない。

**How to apply:** 見慣れない未追跡ファイル・ディレクトリを削除する前に、必ず
`git diff`(部署ファイル・関連mdファイル含む)や `git log` で、直近に自分以外が
書いたと思われる記述がないか確認する。関連する記述が見つかった場合、それは
「意図しない」ものではなく「別セッションの意図した作業」である可能性が高いので、
即座に削除せず、まず秘書に確認を仰ぐ。特に本番公開されうる文書(プライバシーポリシー等)は
より慎重に扱う。
