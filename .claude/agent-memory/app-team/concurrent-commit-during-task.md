PhotoTimerの課金仕様変更(2026-09-06)作業中、自分は一度もgit commitを実行していないにもかかわらず、
作業の途中(CEOからの訂正指示が届く直前)でHEADに想定外のコミット
(`有料機能を最終確定: 演出パターン・自作リスト・場所・複数選択削除の4つ`、著者takataka0307・
Claude co-author)が追加されているのを発見した。中身は自分がその時点まで編集した内容の
スナップショットで、CEOの訂正(自作リストは無料に戻さず有料のまま据え置く)より前の
誤った状態(isCustomListsEnabled=true)を含んでいた。

**Why:** 秘書(または並行して動く別セッション)が、区切りの前に先回りしてコミットすることがある。
自分の作業ツリー上の続く修正は差分として正しく残るため実害は無かったが、気づかずに
「HEADの内容だけ」を完了報告してしまうと、訂正前の誤った状態を最終成果として伝えてしまう
リスクがあった。

**How to apply:** 完了報告を書く前に`git log --oneline -5`で直近のコミットを確認し、
自分が実行していないコミットが無いかを必ずチェックする。見つけた場合は、
(1) そのコミットの内容(`git show <hash>:<path>`)と現在の作業ツリーの差分を比較し、
矛盾する変更が無いか確認し、(2) 秘書への報告に「このコミットは自分が行ったものではない」
「作業ツリーの現在の状態が正しい最終形である」ことを明記する。自分からコミットを
やり直したり打ち消したりする操作(commit --amend, reset等)は行わない(「秘書だけがコミットする」
という運用ルールに反するため)。
